
# Loan Approval Prediction — Data Mining Project

## Project Description
In this project, we will apply data mining techniques to a loan application dataset collected from Kaggle. The dataset contains applicant details such as income, education, credit history, and loan amount. Our goal is to **classify** loan applications into two categories — **Approved (Y)** or **Not Approved (N)** — and to use **clustering** to group applicants with similar profiles and discover common patterns among them.

## Objectives
- Clean and preprocess the dataset (missing values, encoding, scaling).
- Explore the data to identify the key factors that influence loan approval.
- Build and compare classification models to predict loan status.
- Apply clustering techniques (e.g., K-Means) to group similar applicants.
- Evaluate the models using metrics such as accuracy, precision, recall, and F1-score.

## Motivation
We chose this problem because loan approval is a real-world decision that is usually done manually, making it slow and prone to bias. Applying data mining to this dataset shows how classification and clustering can support faster, fairer, and more consistent decisions. The dataset is also well-suited for practicing data mining concepts, as it includes realistic challenges such as missing values and a mix of categorical and numerical features.

## Dataset
Collected from Kaggle: [Loan Prediction — Dream Housing Finance](https://www.kaggle.com/code/ufffnick/loan-prediction-dream-housing-finance/input) — Target: `Loan_Status` (Y/N)
